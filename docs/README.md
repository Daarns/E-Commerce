## Reading Guide

**For Getting Started:**
1. Start with [../README.md](../README.md) for project overview
2. Follow [backend/SETUP.md](./backend/SETUP.md) and [frontend/SETUP.md](./frontend/SETUP.md)
3. Refer to [API.md](./API.md) for endpoint documentation

**For Architecture Understanding:**
1. Read [backend/ARCHITECTURE.md](./backend/ARCHITECTURE.md) for system design
2. Read [frontend/ARCHITECTURE.md](./frontend/ARCHITECTURE.md) for UI patterns
3. Reference [ARCHITECTURE.md](./ARCHITECTURE.md) for overall system design

**For Development:**
1. Use architecture docs to understand code organization
2. Reference API docs for endpoint contracts
3. Check setup guides for environment configuration
